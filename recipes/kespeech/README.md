# KeSpeech evaluation recipe

KeSpeech contains standard Mandarin and eight regional varieties. Its official
license permits non-commercial use but prohibits redistribution and adaptations.
This repository therefore distributes preparation code, identifiers derived at
run time, and aggregate checks only, not KeSpeech transcripts or pairing rows.

The paper protocol pairs each 19,212-utterance official test item with a
different utterance from the same speaker and split. Use the same frozen pairing
seed across all four context modes.
